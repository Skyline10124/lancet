# ADR 0003：直接写宿主工作目录与按调用沙箱

> 本 ADR 随对应改动合并即视为接受。

## 背景

2026-11-21，维护者决定彻底简化 `lancet-node` 的工作区模型，不再采用影子工作区、发布事务（[#7](https://github.com/Skyline10124/lancet/issues/7)）以及多轮 Git 专用设计。

维护者原话：

- “现在就做最简单的，我不想做 git、shadow 还有什么 revert，什么 diff，全删了，我就一个沙箱加一个 act，够了”
- “hidden 也删了”
- “什么都不要留，现在什么承诺都别做”

原有的影子工作区、宿主同步、冲突重算、五阶段发布事务、崩溃恢复发布日志、`hidden`/`regenerable` 路径规则与私有 `.git` 保留规则为节点引入了大量复杂度与状态，而当前阶段的核心诉求是最小的“沙箱 + `act`”。

## 决策

1. **可写目录直接写宿主。** 可写目录直接对应宿主目录，写入立即生效。节点不保留前态，不撤回，不生成 diff；取消影子工作区、待定改动、内置 `commit()` 与 `discard()`，以及 `fs.status`、`fs.diff`、`fs.reset`。
2. **取消路径规则与 Git 特判。** 取消 `[[dir]]` 中的路径规则 `hidden` 与 `regenerable`，授予的目录整体可见。Git 不做专门处理，`.git` 与目录中的其他文件、目录一视同仁。
3. **直接写入的回执口径。** 每次实际修改宿主的直接写入在回执中记一条 `Write`：`action = "write"`，`residue = NotRetained`，`diff` 为空，`diff_truncated = false`。`lancet-protocol` 协议本身不变。
4. **执行环境随 [#8](https://github.com/Skyline10124/lancet/issues/8) 实现。** 每次 `proc.*` 调用新建执行环境，调用结束、超限或取消时整组终止；具体细节随 [#8](https://github.com/Skyline10124/lancet/issues/8) 定。

## 归属

| 概念 | 状态持有者 | 规则执行者 | 只使用结果的组件 |
| --- | --- | --- | --- |
| 工作目录授权 | 节点配置 | 配置加载与启动校验 | 目录资源、分发层、协议服务 |
| 宿主目录读写 | 宿主文件系统 | 目录资源（`HostDir`） | 工具组件、分发层 |
| 调用记录与回执 | 节点状态目录（`calls/`） | 账本与协议服务 | 调用方 |
| 写入 effect 记录 | 本次 `act` 回执 | 分发层 | 协议服务、调用方 |

## 否决的方案

| 方案 | 否决理由 |
| --- | --- |
| 影子工作区、待定改动与发布事务（[ADR 0002 第 6 节](0002-lancet-node-api-tools-and-act.md#6-影子工作区待定改动与发布)） | 引入宿主同步、冲突处理、事务撤回与崩溃恢复等大量复杂度，不再采用 |
| `hidden` 与 `regenerable` 路径规则 | 规则匹配与边界特判增加配置与路径解析复杂度，不再采用 |
| 私有 `.git` 保留与同步方案 | 多轮 Git 专用设计不再采用，`.git` 按普通目录处理 |

## 影响

- 写入立即生效，脚本后续失败时可能只完成一部分；
- 宿主上同时发生的修改不会被发现；
- 可写的 git 仓库，其 `.git` 也可以被改动，包括 hooks 与 config；
- 取代关系：整节取代 [ADR 0002](0002-lancet-node-api-tools-and-act.md#6-影子工作区待定改动与发布) 第 6 节；取代 [ADR 0002 第 5 节](0002-lancet-node-api-tools-and-act.md#5-工作区与节点配置) 中 `hidden` 与 `regenerable` 的部分，以及第 1 至 4 节、第 7 节里与影子、待定改动、发布相关的条款。
